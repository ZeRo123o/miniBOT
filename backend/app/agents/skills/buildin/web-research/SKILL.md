# 网络调研

当问题涉及最新信息、网页资料、产品变化、公开事实核查或需要多个来源相互印证时，使用本 Skill。

## 工作流程

1. 明确用户要解决的问题、时间范围和地域范围；信息已经明确时不要重复追问。
2. 将问题拆成少量可独立检索的事实点，为每个事实点设计具体搜索词。
3. 使用 `tavily_search` 搜索。优先选择官方文档、政府机构、原始公告、研究论文和项目仓库。
4. 对关键结论至少寻找两个相互独立的来源。若只有单一来源，明确说明证据有限。
5. 对冲突信息比较发布日期、事件发生日期、来源权威性和统计口径，不要静默选择更符合预期的一方。
6. 输出结论时区分已确认事实、合理推断和仍不确定的信息。

## 搜索原则

- 搜索词应包含关键实体、主题和必要的年份或版本号。
- 最新信息必须核对实际发布日期，不能只依赖搜索结果排序。
- 不要把搜索摘要当作完整证据；需要依据来源页面能够支持的内容作答。
- 遇到来源无法访问或内容不足时，调整关键词继续检索，不要编造缺失信息。

## 输出格式

- 先给出直接结论，再给出关键依据。
- 对重要事实附上来源标题和 URL。
- 多个来源存在分歧时，单独列出差异与判断依据。
- 不输出无关的搜索过程或冗长日志。
